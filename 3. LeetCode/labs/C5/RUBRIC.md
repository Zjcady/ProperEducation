# C5 rubric

| # | Criterion |
|---|---|
| 1 | All tests pass offline. |
| 2 | Learner can explain RAG in one sentence and draw the four stages. |
| 3 | Chunks respect `max_chars`, carry their heading, and overlap by whole words. Learner can say why overlap exists. |
| 4 | Learner can explain tf-idf and cosine similarity in plain words, and why a real embedding model beats bag-of-words. |
| 5 | Answers cite sources as [n] and the prompt tells the model to admit when sources don't cover the question. |
| 6 | Learner ran the eval, recorded the hit rate, tried one change, and recorded its effect in NOTES.md. |
| 7 | Live answer about "next greater element" cites the stack card. |
