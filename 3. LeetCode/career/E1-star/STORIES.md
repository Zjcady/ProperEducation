# STAR stories

Keep each spoken version under two minutes. Action is the longest part.

Lockheed maps behavioral questions to its five Full Spectrum Leadership imperatives:
**Deliver Results; Shape the Future; Build Effective Relationships; Energize the Team; Model Personal Excellence, Integrity and Accountability**
([Lockheed Martin](https://lockheedmartin.com/en-us/who-we-are/leadership-governance/full-spectrum-leadership.html);
[TechPrep](https://www.techprep.app/blog/lockheed-martin-interview-process)). Each story below is tagged with
the one it best shows. Say the imperative's words once, naturally, in your Result. Other primes use their own
lists (RTX: Trust, Respect, Accountability, Collaboration, Innovation; Northrop: Integrity, Innovation,
Accountability), so the same stories retag in a minute.

## Story 6 · Why defense, why this company

Facts you can use (each one sourced; pick one or two, don't recite the list):
- **LM Navigator**: secure chat over multiple LLMs, with file uploads and access to custom agents; about 75,000 employees use it. [LM feature, 2025](https://www.lockheedmartin.com/en-us/news/features/2025/astris-ai-lockheed-martin-trusted-innovation-new-industries.html), [Astris AI](https://www.astrisai.com/)
- **Genesis**: a low-code/no-code, self-hosted, on-premises builder for generative AI agents, with no-code RAG and access controlled by Active Directory groups; 16,000+ agents built since the start of 2025. [LMCO RFI response to NITRD, 2025](https://files.nitrd.gov/90-fr-9088/LMCO-AI-RFI-2025.pdf), [LM feature, 2025](https://www.lockheedmartin.com/en-us/news/features/2025/astris-ai-lockheed-martin-trusted-innovation-new-industries.html)
- **Jiminy**: an internally hosted VS Code extension coding agent. [LMCO RFI response](https://files.nitrd.gov/90-fr-9088/LMCO-AI-RFI-2025.pdf)
- **AI Factory**: runs on NVIDIA DGX SuperPOD; 8,000+ engineers and developers used it by late 2024; Navigator use cases include generating and testing code. [LM feature, Oct 2024](https://www.lockheedmartin.com/en-us/news/features/2024/empowering-innovation-with-secure-generative-ai-across-enterprise.html)
- **Gemini on-prem**: Google's Gemini models are being brought into the AI Factory inside secure, on-premises, air-gapped environments. [Google Cloud, Oct 2025](https://www.googlecloudpresscorner.com/2025-10-29-Lockheed-Martin-and-Google-Public-Sector-to-Bring-Generative-AI-to-On-Premise-Infrastructure-for-National-Security)
- Mandatory training comes before anyone uses Navigator or the AI Factory. [LMCO RFI response](https://files.nitrd.gov/90-fr-9088/LMCO-AI-RFI-2025.pdf)

The shape that works: one honest personal reason, one concrete thing about their AI work that connects to something you built (C3 is a small Genesis-style tool integration; C5 is no-code RAG done by hand), and what you'd want to work on.
