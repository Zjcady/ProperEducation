# E3 rubric

| # | Criterion |
|---|---|
| 1 | Both talks fit in ten minutes; the log shows times. |
| 2 | The drawing has every component the code actually has, and nothing the code doesn't. |
| 3 | The key decision is stated as a trade-off, not a feature. |
| 4 | The 10x answer names the first thing that breaks and one concrete change. |
| 5 | Three follow-ups answered without notes on each talk. |
| 6 | The learner can give Talk 1 cold, a week later. |
