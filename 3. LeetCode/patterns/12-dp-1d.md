# 1-D Dynamic Programming

**Reach for it when you see**
- "number of ways", "minimum cost", "maximum value", "can it be done"
- choices at each step where today's answer depends on earlier answers
- a recursion that recomputes the same thing (fib-shaped)

**The move**
1. Define `dp[i]` in one sentence: "the best answer for the first i items."
2. Write the recurrence: how does `dp[i]` come from smaller `dp`?
3. Base case. 4. Loop. Say step 1 out loud before anything else.

**Template**
```python
dp = [0] * (n + 1)
dp[0] = base
for i in range(1, n + 1):
    dp[i] = combine(dp[i - 1], dp[i - 2], ...)
return dp[n]
```

**Gotchas**
- Start with the memoized recursion if the loop isn't obvious. `@functools.lru_cache(None)` on a helper is legal DP.
- House Robber: `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`. Rob or skip. Most 1-D DP is "take or skip".
- Coin Change wants a minimum: init with `inf`, not 0.
- Max Product Subarray needs the *min* too, because a negative times a negative flips.
