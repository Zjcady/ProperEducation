# 2-D Dynamic Programming

**Reach for it when you see**
- two strings, or a grid, or two indices that both move
- "subsequence" of two things, "paths through a grid"

**The move**
Same recipe as 1-D, but `dp[i][j]` depends on `dp[i-1][j]`, `dp[i][j-1]`, `dp[i-1][j-1]`. Define it in one sentence first.

**Template**
```python
dp = [[0] * (m + 1) for _ in range(n + 1)]
for i in range(1, n + 1):
    for j in range(1, m + 1):
        if a[i-1] == b[j-1]:
            dp[i][j] = dp[i-1][j-1] + 1
        else:
            dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

**Gotchas**
- `[[0]*m]*n` makes n references to ONE list. Always use the comprehension above.
- The extra row and column of zeros means you never special-case index 0.
- Unique Paths: `dp[i][j] = dp[i-1][j] + dp[i][j-1]`. The grid's edges are all 1.
