# Mock interviews

One per week on Saturdays, once you've solved five problems. 30 minutes. `coach.py mock` picks a problem you've already solved; the point is to practice *talking* through a solution under time, not to meet a new problem.

Each mock leaves a file here: `YYYY-MM-DD-<id>-<slug>.md` with the four-area score Claude gives you and a section you write yourself: what to do differently next time. Read the last three before the next mock.
